Examples

Whole apps, each one small enough to read

Each example is a real app in the repository's examples/ directory, built with Roc Solid from the database to the browser: the pieces fitting together, not a snippet. Each has a README that tours it and points to the file behind each feature, and a page here with its numbers and, for most, screenshots. All but hello have their own tests.

Where to start#

Start with hello: one page with a counting button, and one endpoint. It's the app Getting started makes. Then read Tasks, written to be read first: file routing, middleware, a database, pages that read endpoints, forms that work without JavaScript, and optimistic updates, done the plain way, with comments on why each piece is where it is. Then pick the app that shows what you need from the table below.

To run one, set up the repository (just setup), then start the app from its own directory, so its database file lands beside it. rocx dev builds it, serves it at http://localhost:8080 and rebuilds on save. just examples builds, checks and tests an app as the repository's checks do.

How they're measured#

Measured on 2026-11-24, at commit a15fd49, with the compiler rocx-fork-4674b5973d, on an Apple M5, 10 cores. just example-apps rebuilds each app's browser half (rocx build --client, then the wasm with --opt=size, as just examples does) and compresses it as this site measures its own (gzip level 9, brotli quality 11). Then it counts pages, endpoints, the app's own lines of Roc (no blank lines, nothing rocx build writes, no tests), expects and node tests.

just example-apps --bench reruns echo's server benchmark, and just example-shots takes the screenshots. This site's build only reads what they wrote, since a dozen wasm builds take minutes. How the browser's runtime compares with other frameworks: js-framework-benchmark.

The sizes are what a browser downloads compressed. The Roc Solid server sends files as they are, so in production a CDN or a compressing proxy (GitHub Pages, for this site) gets them down to these sizes.
