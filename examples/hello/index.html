hello

The app Getting started makes: a page with a button that counts its clicks, and an endpoint. Its main.roc is the one rocx dev writes for an app without one.

What it shows#

  • An endpoint, GET /hello
  • The smallest browser half: where every app starts

Its page#

All of it: a signal, a button that sets it, and text that reads it. The server renders it; the browser makes the button count.

Run it#

With the toolchain set up (just setup), start it from its own directory: it builds, serves at http://127.0.0.1:8080 and builds again when you save. Its README says what to look at.
